About TempleBook

This web application allows users to check temple crowd levels and book darshana or abhisheka slots with ease. It provides real-time crowd updates, simple online booking, and a dedicated section to view upcoming bookings.

It provides role-based access to both devotees and admin to ensure safety.

In the admin section, the admin has access to add new temples to the web app.
